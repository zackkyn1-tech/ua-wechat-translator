# Моя музика — архів пісень для гітариста

Android-додаток (Kotlin + Jetpack Compose).

## Можливості
- **Категорії** (Рок, Блюз…) з обкладинками.
- **Пісні** в категоріях: назва, виконавець, обкладинка, пошук.
- Вкладки пісні:
  - **🎙 Голосові** — запис з мікрофона прямо в пісню, програвання, швидкість 0.5x–1.25x, повтор, перейменування, «поділитися».
  - **Текст** — текст пісні (зберігається автоматично).
  - **Акорди / таби** — моноширинний шрифт для табулатур.
  - **Ноти** — фото/скани нот (зум), PDF, файли Guitar Pro.
  - **Музика** — оригінал або мінусовка, з уповільненням і повтором.
- **Резервна копія** (меню ⋮ на головному екрані) — все в один .zip, відновлення з нього.

Усі дані (пісні, обкладинки, ноти, голосові) зберігаються лише на телефоні, у внутрішній пам'яті додатку. Автоматичне копіювання в Google Drive вимкнене. Резервну копію (.zip) можна зберегти вручну в будь-яку папку телефону.

## Збірка
```
export ANDROID_HOME=/шлях/до/android-sdk
./gradlew assembleRelease
# APK: app/build/outputs/apk/release/app-release.apk
```
Ключ підпису лежить у `keystore/` — ним треба підписувати всі наступні версії,
щоб оновлення ставились поверх без втрати даних.
